 🚀 Task Aura — To-Do List Website

**Task Aura** is a modern and user-friendly To-Do List website built using HTML, CSS, and JavaScript. It helps users organize daily activities, manage tasks, and improve productivity through a simple and interactive interface.

✨ Features

- ✅ Add and manage daily tasks
- 🕒 Set task times and schedules
- 📋 View and organize your tasks
- 🗑️ Delete or clear tasks
- 🎨 Modern and attractive user interface
- 🌙 Light and dark theme toggle
- 📱 Responsive design for different screen sizes

 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and responsive design
- **JavaScript** — Interactive functionality

 📂 Project Structure

```text
Task-Aura/
├── index.html
├── style.css
├── script.js
└── README.md
```

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start managing your daily tasks!
